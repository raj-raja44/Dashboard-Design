# 📊 Interactive Power BI Dashboard

## 📌 Project Overview

This project focuses on creating an interactive Power BI dashboard to analyze business performance through key performance indicators (KPIs), sales, profit, and growth trends.

The dashboard uses interactive filters and visualizations to make business data easier to understand and support data-driven decision making.

## 🎯 Objectives

- Analyze sales and profit performance
- Track important business KPIs
- Identify trends over time
- Create interactive data visualizations
- Compare business performance using filters
- Present insights through an easy-to-understand dashboard

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft PowerPoint
- Data Visualization
- Business Intelligence

## 📈 Dashboard Features

The dashboard includes:

- Sales KPI analysis
- Profit analysis
- Growth analysis
- Time-series analysis
- Interactive filters
- Charts and visualizations
- Business performance indicators
